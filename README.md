# 🚀 SiteForge AI

SiteForge AI is an **AI-powered website builder** that lets users create websites simply by describing what they want. Enter a prompt, and AI generates a complete website for you.

## ✨ Features

* 🤖 Generate websites using AI prompts
* 🎨 Create modern, responsive websites
* 👥 Community to explore and share generated websites
* 💳 Stripe payment integration
* 📧 Brevo API for email services
* 🔐 User authentication
* 🚀 Deploy websites easily with Vercel
* 🐙 GitHub integration

## 🛠️ Tech Stack

**Frontend:** React.js
**Backend:** Node.js, Express.js
**Database:** MongoDB
**AI:** AI-powered website generation
**Payments:** Stripe
**Email:** Brevo API
**Deployment:** Vercel
**Version Control:** Git & GitHub

## ⚙️ How It Works

1. Enter a prompt describing your website.
2. SiteForge AI generates the website.
3. Preview and customize the result.
4. Save or publish your website.
5. Share it with the SiteForge community.

## 🚀 Deployment

The project is deployed using **Vercel**, with the source code managed through **GitHub**.

## 📌 Goal

SiteForge AI aims to make website development faster and more accessible by allowing anyone to **build websites using natural language prompts**.
